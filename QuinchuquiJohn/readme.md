The objective of Workshop 3 was to improve the previous website by adding interactivity using HTML, CSS, JavaScript, and jQuery. The project was developed from the website created in the previous workshop, keeping its general visual style and content while adding the new sections and functions required for this activity. The workshop required a navigation bar, a hero section, an image gallery, a contact form, responsive CSS, and different interactive effects implemented with jQuery.

The index.html file was modified. The original information about the student, university, and academic interests was preserved, but new elements were added. A hero section was created at the top of the page with a title, a short description, and a button called “Change Background.” The navigation bar was also updated so that users can easily access the main sections of the website, including Home, Courses, Schedule, Hobbies, Gallery, and Contact.

Another important addition was the image gallery. Four images were included in the gallery: the profile image, the university image, and two additional images named gallery3.jpg and gallery4.jpg. These images are displayed using CSS Grid, which makes the gallery organized and adaptable to different screen sizes. When a user clicks on one of the images, it is enlarged inside a modal window. The modal uses a dark transparent background to focus attention on the selected image and can be closed by clicking the “X” button or outside the enlarged image.

A contact form was also added to the main page. This form contains fields for the user's name, email address, and message, as well as a submit button. jQuery was used to validate the information before allowing the form to be considered complete. If a required field is empty, the user receives an alert explaining what information is missing. The email address is also checked to make sure that it follows a valid format. When all the information is correct, the webpage displays the message “Form submitted successfully!”, as required by the workshop.

The style.css file was also updated. Flexbox and CSS Grid were used to organize different sections of the website. Hover effects were added to navigation links, buttons, gallery images, cards, and other interactive elements. Media queries were included so that the website can adapt to smaller screens such as tablets and mobile phones. These changes satisfy the styling and responsiveness requirements of the workshop.

Some improvements were made to the Schedule and Hobbies pages. Initially, the text on these pages was difficult to read because the pixel-art background image had many dark and bright colors. To solve this problem, the CSS was reorganized and backgrounds were added behind the main content, tables, and hobby cards. This increased the contrast and made the information easier to read without removing the original background design.

And the script.js file was created to manage the jQuery interactions. It includes three main functions: changing the hero background to a random color, displaying gallery images inside a modal, and validating the contact form. jQuery was linked before script.js in the HTML file so that all functions work correctly.

One of the main challenges during the implementation was maintaining the original visual design while adding the new interactive requirements. Another challenge was improving text visibility on pages that used the background image. These problems were solved by reorganizing the CSS, improving contrast, and separating the styles for each section.

The final website combines the original HTML and CSS project with new jQuery functionality, creating a more interactive, responsive, and visually organized webpage.
